# Quantum English Learn — content libraries

Public content for the **Quantum English Learn** Android app.
The app reads `catalog.json` and downloads the libraries listed in it:

- `<id>-<version>.enpack` — text pack (stories, conversations, vocabulary, quizzes)
- `<id>-<version>.audio.enpack` — optional studio voice pack

Files are generated by `tools/content_builder/build_pack.py` and `build_catalog.py`
in the app repository — do not edit them by hand. Every download is checked
against the sha256 in `catalog.json`.
